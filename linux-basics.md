This module covers essential Linux commands and concepts used in file management, navigation, permissions, and system administration.

---

## 1. File System Navigation

Linux uses a directory-based structure. I learned how to move and locate myself in the system.

### Commands:
1. `pwd` → shows current directory
2. `cd` → change directory
3. `ls` → list files and folders

### Key Idea:
You must always know your location in the system when working in Linux.

---

## 2. File and Directory Management

These commands help create, move, copy, and delete files.

### Commands:
1. `touch` → create a file
2. `mkdir` → create a directory
3. `cp` → copy files/folders
4. `mv` → move or rename files
5. `rm` → delete files

### Key Idea:
File operations are the core of Linux system control.

---

## 3. Viewing and Comparing Files

Used to inspect and analyze file content.

### Commands:
1. `cat` → show full file content
2. `head` → show first lines
3. `tail` → show last lines
4. `diff` → compare two files

### Key Idea:
These tools help analyze logs and configurations.

---

## 4. Permissions and Ownership

Linux security is based on permissions.

### Commands:
1. `ls -l` → view permissions
2. `chmod` → change permissions
3. `chown` → change ownership

### Key Idea:
Permissions control access (read, write, execute).

---

## 5. User Management

Basic system administration concepts.

### Topics:
1. Creating users
2. Setting passwords
3. Managing groups
4. Locking/unlocking accounts
5. Deleting users

---

## 6. Summary

- Linux is command-line based
- File management is fundamental
- Permissions are critical for security
- Mistakes (like `rm`) can be permanent
